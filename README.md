# reels-skill

Плагин для [Claude Code](https://docs.claude.com/en/docs/claude-code) — генерирует сценарии Instagram Reels / TikTok / Shorts / VK Клипов **на русском языке** из git-репозитория. На основе коммитов, инцидентов и релизов.

Сделан так, чтобы:

1. Брать не одиночный коммит, а арку из 5–20 коммитов под одной болью.
2. Не писать AI-русским (есть отдельный чёрный список фраз).
3. Не повторять одну и ту же структуру / хук в каждом видео.
4. Извлекать из репозитория конкретные слова и числа — не «крутая фича», а имя сервиса и реальный counter.

## Установка

В Claude Code:

```bash
/plugin marketplace add jointimealex/reels-skill
/plugin install reels-skill
```

После этого скилл `writing-reels-from-repo` активируется автоматически по триггерам:

- «сделай рилс из репозитория»
- «сценарий рилса на тему X»
- «реелс про последнюю неделю коммитов»
- «build in public день N»
- «короткое видео про фичу / баг / деплой»

## Как пользоваться

В директории своего проекта (с `.git`):

```
напиши рилс из последних коммитов
```

Скилл сам:

1. Соберёт `git log` за 3 недели + проверит `CLAUDE.md` / `MEMORY.md` / `README.md`.
2. Сгруппирует коммиты в 2–4 арки и оценит каждую по 6 осям.
3. Выдаст 2–3 кандидата → ты выбираешь.
4. Извлечёт лексикон проекта (термины, имена, числа).
5. Покажет 5 story atoms → ты подтверждаешь.
6. Спросит, какие хук-формулы ты использовал в последних 5 эпизодах.
7. Выдаст скрипт с тайм-кодами, бюджетом слов, b-roll, подписью и описанием обложки.

## Чем отличается от «сделай рилс, ChatGPT»

| | Голый промпт | reels-skill |
| --- | --- | --- |
| Источник | Твой описание | Реальные коммиты + логи |
| Объём | Один коммит = один рилс | Арки из 5–20 коммитов |
| Лексика | AI-русский | Чёрный список фраз + speak-test |
| Хуки | Один-два паттерна | 22 формулы с ротацией |
| Метафоры | Generic («как иголка в стоге сена») | Запрещены, кроме случая, когда буквально в коде |
| Скоринг | Нет | 6 осей, отказ при score <5 |

## Структура

```
.claude-plugin/
  plugin.json                    # манифест плагина
skills/
  writing-reels-from-repo/
    SKILL.md                     # главный workflow
    references/
      ban-list-ru.md             # запрещённые фразы и замены
      hook-bank-ru.md            # 22 хук-формулы с примерами
      register-ru.md             # как звучит живой инженер vs AI
      arc-clustering.md          # приёмы агрегации коммитов
```

## Под капотом

Скилл — это markdown-документ с инструкциями для Claude. Тяжёлый материал (чёрные списки, формулы, примеры) вынесен в `references/` и подгружается по ссылке, когда нужен. Это и для скорости, и для того, чтобы Claude не пытался следовать «сжатой шпаргалке», игнорируя детали.
