# Regiстр устной русской речи для рилсов

Как звучит живой инженер vs. как звучит AI. Каждый пример — реальная трансформация.

## Базовый принцип

**Voiceover пишется для устного произнесения, не для чтения.**

Если ты можешь представить эту фразу в письме коллеге в Telegram — оставляй. Если она похожа на пост в корпоративном блоге — переписывай.

## Правила (по убыванию частоты ошибок)

### 1. Короткие предложения

Voiceover-блок = максимум 12 слов в одном предложении. Лучше — 6–8. Если предложение длиннее — режь на два через точку.

```
❌ Я обнаружил, что одна из используемых нами библиотек кэширует
   ответы, в том числе ошибки, что приводило к тому, что часть
   пользователей видела устаревшие данные.

✅ Одна библиотека кэшировала ответы. Включая ошибки.
   Часть юзеров видела вчерашние данные.
```

### 2. Активный залог

```
❌ Было замечено, что приложение падает по понедельникам.
✅ Я заметил: приложение падает по понедельникам.

❌ Бэкап был восстановлен через час.
✅ Я восстановил бэкап за час.

❌ Был принят костыль вместо нормального фикса.
✅ Закостылил. Нормальный фикс — потом.
```

### 3. Глаголы вместо существительных-действий

Канцелярит любит превращать действия в существительные. Воз­вращай их в глаголы.

```
❌ Использование этой библиотеки даёт ускорение в 3 раза.
✅ С этой библиотекой стало в 3 раза быстрее.

❌ Выполнение миграции заняло двенадцать часов.
✅ Миграция шла двенадцать часов.

❌ Принятие решения о переписывании было сложным.
✅ Решиться переписать было сложно.
```

### 4. «Я» в начале — нормально

В письменной речи учат избегать «я». В voiceover — наоборот. Build-in-public о тебе.

```
❌ Возникла необходимость переписать модуль аутентификации.
✅ Я понял, что аутентификацию надо переписать.

❌ Имеет смысл протестировать гипотезу.
✅ Я решил проверить.
```

### 5. Цифры — буквально

«Много», «несколько», «достаточно», «значительно» — мусор. Заменяй на реальное число.

```
❌ Сервер обрабатывал значительное количество запросов.
✅ Сервер держал 1200 запросов в секунду.

❌ Юзеры начали жаловаться.
✅ За час пришло 47 жалоб.

❌ Я потратил много времени.
✅ Я потратил три вечера.
```

### 6. Жаргон + одна-секундная аналогия

Терминам нельзя без пояснения, если зритель — смешанный. Но и не нужно университетское определение.

```
❌ JWT-токен — это JSON Web Token, стандарт для передачи
   информации между двумя сторонами.

✅ JWT — это типа цифровой пропуск. С подписью.

❌ Race condition — это состояние гонки, когда результат
   зависит от порядка выполнения процессов.

✅ Race condition: два процесса одновременно тянутся за одним —
   и один портит другому.
```

### 7. Конкретные имена, не категории

Имена сервисов / библиотек / файлов делают речь живой.

```
❌ Я обновил библиотеку для работы с базой данных.
✅ Я обновил Prisma с 5.0 до 5.7.

❌ Поправил конфиг.
✅ Поправил `nginx.conf`. Одну строку. `proxy_read_timeout`.

❌ Один из микросервисов начал лагать.
✅ `payments-worker` начал лагать.
```

### 8. Длинные причастия и деепричастия — резать

`-щий`, `-ющий`, `-вший`, `-вшись`, `-ясь` — почти всегда канцелярит. Заменяй придаточным.

```
❌ Используя этот подход, я смог решить проблему.
✅ Я попробовал так — и сработало.

❌ Запустив тесты, обнаружил утечку памяти.
✅ Запустил тесты. Увидел утечку памяти.

❌ Микросервис, обрабатывающий платежи, упал.
✅ Микросервис, который держит платежи, упал.
```

### 9. «Это» без союза — нормально

В письменной речи учат соединять. В устной — точка и «это» работает.

```
❌ Я обнаружил, что в кэше лежали старые данные, что и было
   причиной ошибки.
✅ В кэше лежали старые данные. Это и был баг.
```

### 10. Эмоция — конкретно

«Я был в шоке», «это было ужасно» — пусто. Покажи реакцию через действие.

```
❌ Я был в шоке от количества ошибок.
✅ Я закрыл Sentry и пошёл пить кофе. Открыл — то же самое.

❌ Это был кошмар.
✅ Я смотрел на этот лог сорок минут.
```

## Тест перед выдачей

1. **Speak-test.** Прочитай каждый voiceover-блок про себя с интонацией. Споткнулся? Длинно? Чувствуется AI? Переписывай.
2. **Telegram-test.** Может ли это быть твоим сообщением другу в чате? Если нет — переписывай.
3. **Random-test.** Замени все существительные на «фигня». Звучит как нормальное русское предложение? Должно — структура должна работать без слов.

## Анти-примеры (что НЕ переписывать)

Если фраза уже **звучит как речь** — не трогай её ради «литературности». «Прод упал» лучше, чем «продакшен-окружение оказалось недоступным». Кор-стилистика рилса — корявая, но живая.

Иногда даже мат уместен (если канал автора это поддерживает). Не цензурируй там, где автор сам не цензурирует. Build-in-public ценит аутентичность.
