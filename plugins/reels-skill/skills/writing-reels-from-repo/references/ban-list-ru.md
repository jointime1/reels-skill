# Чёрный список фраз (RU)

Список слов и оборотов, которые автоматически делают сценарий рилса похожим на AI-копирайт. Прежде чем выдать скрипт пользователю — прогони voiceover и subtitles через этот фильтр.

Каждое запрещённое слово либо вырезается, либо заменяется по шаблону `❌ → ✅`.

## 1. AI-штампы (вырезать всегда)

Эти фразы — главный маркер «текст написал бот». Если хотя бы одна осталась в финальном скрипте, пользователь сразу видит AI.

| ❌ Запрещено | ✅ Что делать |
| --- | --- |
| «Давайте разберёмся» | Сразу к делу. Cold open. |
| «Итак» (в начале блока) | Удалить. |
| «Погружаемся в…» / «Погружаюсь в…» | Удалить или заменить на конкретное действие («Открываю Sentry»). |
| «Представьте» / «Представьте себе» | Дать сразу факт, без «представь». |
| «В этом видео я расскажу/покажу» | Cold open. Никогда не анонсируй содержание видео — показывай. |
| «Сегодня поговорим о…» | Удалить, начать с факта. |
| «Хочу поделиться» | Удалить. |
| «И знаете что?» | Удалить. |
| «А теперь самое интересное» | Удалить. Если интересное — оно говорит само. |
| «Кстати» / «К слову» (в середине voiceover) | Удалить либо разбить на два предложения. |
| «На самом деле…» (как вводное) | Удалить. Сказать утверждение прямо. |
| «По сути» | Удалить. |

## 2. Канцелярит (вырезать всегда)

Делает речь чужой. Все эти слова — из протоколов и пресс-релизов, не из устной речи.

| ❌ Запрещено | ✅ Замена |
| --- | --- |
| «является» (как смысловой глагол) | Любой нормальный глагол или вообще пропустить. «Бэкенд является питоновским» → «Бэкенд на питоне» |
| «представляет собой» | «это» или конкретный глагол |
| «осуществляет» | Конкретный глагол: «делает», «считает», «отправляет» |
| «производит» (в смысле «делает») | «делает», «считает», «генерирует» |
| «данный», «данная», «данное», «данные» (как местоимение) | «этот», «эта», «это» |
| «вышеуказанный», «нижеследующий» | Удалить или сказать «выше», «ниже» |
| «в рамках» | «когда», «во время», «для» |
| «в связи с» | «из-за», «потому что» |
| «вследствие» | «из-за» |
| «при помощи» | «через», «с помощью» (а лучше — переформулировать) |
| «использование», «решение», «выполнение» как подлежащие | Превратить в глагол. «Использование этой библиотеки даёт…» → «С этой библиотекой получается…» |

## 3. Кальки с английского (вырезать всегда)

Эти конструкции в русской устной речи звучат как перевод. Каждая — мгновенный сигнал «это не русский».

| ❌ Запрещено | ✅ Замена |
| --- | --- |
| «Это о том, как…» (it's about how…) | «Я сделал X», «X сломался», «Мне попался…» |
| «Сделал так, что…» (made it so that…) | «Сделал X», «Поменял X на Y» |
| «Имеет смысл» (makes sense) — самостоятельное | Удалить или «логично», «понятно почему» |
| «В конце дня» (at the end of the day) | «В итоге», «по факту» — или вообще удалить |
| «Таким образом» (как linker) | Удалить. Если нужен переход — точка и новая мысль. |
| «Я был как…» (I was like…) | «Я подумал», «Я сказал» |
| «Сделать разницу» (make a difference) | «Помогло», «изменило ситуацию» |
| «Не имеет смысла» (doesn't make sense) | «не работает», «не сходится» |
| «Брать решение» (take a decision) | «решить», «принять решение» (одно из, но не «брать») |
| «Иметь возможность» (have the ability) | «мочь» |
| «Достаточно (+ прилагательное)» как hedging | Удалить «достаточно». «Достаточно быстро» → «быстро» |

## 4. Маркетинговый тон (вырезать всегда)

Build-in-public ломается о маркетинговую лексику. Под-стейтмент сильнее, чем гипербола.

| ❌ Запрещено | ✅ Замена |
| --- | --- |
| «крутой», «крутая», «крутое» | Конкретика. «Крутой график» → «график за месяц без падений» |
| «топ», «топовый» | Удалить. |
| «потрясающе», «невероятно», «удивительно» | Удалить или показать конкретику, которая впечатляет сама. |
| «киллер-фича», «game-changer» | Конкретное действие, которое стало возможным. |
| «секрет, который никто не расскажет» | Удалить весь блок. |
| «лайфхак» (без иронии) | «трюк», «хак» — лучше показать, чем назвать. |
| «инсайт» (без иронии) | «я понял, что…» |
| «огонь», «бомба», «вырвиглаз» (без self-irony) | Удалить. |
| «фишка» | Удалить или назвать функцию своим именем. |
| «вот это поворот» (вне иронии) | Удалить. |
| «прокачать» (skill, проект) | «улучшить», «переписать» |
| «жирный (фикс/коммит)» | Конкретное число строк / файлов. |

## 5. Generic метафоры (запрещены, кроме одного случая)

| ❌ Запрещено | Исключение |
| --- | --- |
| «иголка в стоге сена» | Только если буквально есть в источнике (имя ветки, comment в коде). |
| «слон в посудной лавке» | То же. |
| «снежный ком» | То же. |
| «эффект бабочки» | То же. |
| «ремонт самолёта в полёте» | То же. |
| «верхушка айсберга» | То же. |
| «прокрустово ложе» | То же. |
| «темная лошадка» | То же. |

**Правило:** метафора в скрипте — только если она ВЫРАСТАЕТ из материала. Имя ветки `iceberg-fix`, комментарий `// snowball started here`, шутка в чате. Иначе — конкретный факт без метафоры.

## 6. Hedging и заполнители (резать)

| ❌ Запрещено | ✅ Замена |
| --- | --- |
| «вроде бы», «как бы» | Удалить. |
| «в принципе» | Удалить. |
| «достаточно», «весьма», «довольно» | Удалить или дать число. |
| «очень-очень» | Удалить. |
| «прям супер» | Удалить. |
| «короче» (как заполнитель) | Удалить. (Если хочется — оставь один раз на весь скрипт.) |
| «такой, типа» | Удалить. |
| «формально», «фактически», «по факту» (как hedging) | Удалить или дать прямое утверждение. «Формально всё ок» → «Sentry чистый — ноль ошибок» |
| «по сути», «по большому счёту» | Удалить. |
| «как такового», «как таковой» | Удалить. |
| «в общем-то», «в целом-то» | Удалить. |

## Алгоритм фильтрации (применяй перед выдачей)

1. Открой текст voiceover.
2. Сделай мысленный grep по таблицам 1–6.
3. На каждый match — замени по правой колонке или удали.
4. Если после замены смысл блока пропал — переписать блок целиком, не пытаясь спасти конструкцию.
5. Прочитай вслух (или мысленно). Споткнулся на причастии (длинном слове с «-щий», «-ющий», «-вший») — заменяй на придаточное «который…».

## Тест на AI-тон

После фильтра прочитай первые 3 предложения скрипта. Они звучат как:

- ❌ Пост в корпоративном блоге

Если ближе к (❌) — переписать заново, с другого хука.
